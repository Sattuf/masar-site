# masar-site

الموقع العام لتطبيق مسار على GitHub Pages: `https://sattuf.github.io/masar-site/`

- `privacy.html` و `terms.html`: سياسة الخصوصية وشروط الاستخدام (يفتحهما التطبيق ويطلبهما Google Play).
- `v1/`: ملفات تحديث المحتوى التي يجلبها التطبيق دون تحديث من المتجر.

لا تُعدَّل هذه الملفات يدوياً: تُولَّد في المستودع الرئيسي (`tools/build-legal.mjs` و `tools/build-static-api.mjs`)
وتُنسخ هنا. التفاصيل في `docs/RELEASE.md` هناك.
